# 1. What is this?
This is a simple C program that reads and adds commands line by line, serving as a basic foundation for an interpreter.

# 2. Why I Made It
To understand how interpreted languages like Python and JavaScript parse and process instructions under the hood.

# 3. How I Did It
I defined a `struct` to represent functions/commands and wrote helper functions to capture, store, and process input line by line.

# 4. How to Use It
1. Clone the repository and navigate to the project folder:
```bash
git clone https://github.com
cd YOUR_REPO_NAME
```

2. Compile the C code using `gcc`:
```bash
gcc compiler.c -o interpreter
```

3. Run the compiled program:
* **On Linux / macOS:**
```bash
./interpreter
```
* **On Windows (CMD):**
```cmd
interpreter.exe
```
